# ڕێنمایی دامەزراندنی فرۆشگای Mang Herbal لەسەر هۆستی خۆت

ئەم پاکەیجە هەموو ئەو شتانەی تێدایە کە پێویستە بۆ ئەوەی فرۆشگاکەت لەسەر دۆمەینی خۆت کار بکات.

## ناوەڕۆکی پاکەیجەکە

| فایل / فۆڵدەر | بۆچی؟ |
|---|---|
| `app.cjs` | فایلی دەستپێکردنی سێرڤەر (بۆ Passenger لە cPanel) |
| `dist/` | سێرڤەری API (ئامادەکراوە، پێویستی بە node_modules نییە) |
| `public/` | وێبسایتەکە (لەگەڵ وێنەی بەرهەمەکان) |
| `database.sql` | داتابەیسی تەواو — هەمان داتای ئێستای فرۆشگاکەتە (بەرهەم، هەژمار، داواکاری، ڕێکخستنەکان) |
| `migrate-existing-db.sql` | تەنها بۆ داتابەیسی کۆن — ستوونە نوێیەکان (ئیمەیڵ و کاتی چوونەژوورەوە) زیاد دەکات |
| `SETUP-GUIDE.md` | ئەم ڕێنماییە |

> **زۆر گرنگ:** ئەم زیپە هەموو داتای فرۆشگاکەتی تێدایە — هەژماری کڕیاران، داواکارییەکان و کلیلە نهێنییەکان. بە هیچ کەسێکی مەدە و لە شوێنێکی پارێزراو هەڵیبگرە.

## هەنگاوی ١ — داتابەیس (Neon)

1. بچۆ بۆ [neon.tech](https://neon.tech) و پرۆژەیەک دروست بکە (خۆڕاییەکەی بەسە).
2. لە Neon، بەشی **SQL Editor** بکەرەوە.

**ئەگەر یەکەمجارە دایدەمەزرێنیت (داتابەیسی بەتاڵ):**
- ناوەڕۆکی فایلی `database.sql` کۆپی بکە و لە SQL Editor جێبەجێی بکە.
- ئەمە هەموو داتای فرۆشگاکەت دروست دەکاتەوە — هەر شتێکی کە لە کاتی دروستکردنی زیپەکە هەبووە: بەرهەمەکان، هەژمارەکان، داواکارییەکان و ڕێکخستنەکان.

**ئەگەر سایتەکەت پێشتر کار دەکات و داتای تێدایە:**
- تەنها ناوەڕۆکی `migrate-existing-db.sql` جێبەجێ بکە. هیچی تر مەکە — داتاکانت وەک خۆی دەمێنێتەوە.

3. لە Neon، دوگمەی **Connect** دابگرە و بەستەرەکە (Connection String) کۆپی بکە — لە هەنگاوی ٤ پێویستت پێیەتی.

## هەنگاوی ٢ — بارکردن بۆ cPanel

1. فایلی زیپەکە لە **File Manager** ی cPanel باربکە.
2. لە فۆڵدەرێک بیکەرەوە (بۆ نموونە `mang-herbal`) — با لە دەرەوەی `public_html` بێت.

## هەنگاوی ٣ — دروستکردنی ئەپی Node.js

1. لە cPanel بگەڕێ بۆ **Setup Node.js App** و **Create Application** دابگرە.
2. ئەمانە دابنێ:
   - **Node.js version**: 20 یان نوێتر
   - **Application mode**: Production
   - **Application root**: ئەو فۆڵدەرەی زیپەکەت تێدا کردەوە (بۆ نموونە `mang-herbal`)
   - **Application URL**: دۆمەینەکەت
   - **Application startup file**: `app.cjs`

## هەنگاوی ٤ — زانیارییە نهێنییەکان (Environment Variables)

لە هەمان پەڕەی Node.js App، لە بەشی **Environment Variables** ئەمانە زیاد بکە:

| ناو | بەها |
|---|---|
| `DATABASE_URL` | بەستەرەکەی Neon کە لە هەنگاوی ١ کۆپیت کرد |
| `SESSION_SECRET` | دەقێکی درێژی هەڕەمەکی (بۆ نموونە ٤٠ پیت و ژمارەی تێکەڵ) — بە کەس مەیدە |
| `NODE_ENV` | `production` |

(PORT پێویست ناکات — cPanel خۆی دایدەنێت.)

## هەنگاوی ٥ — دەستپێکردن

1. دوگمەی **Restart** دابگرە.
2. دۆمەینەکەت بکەرەوە — فرۆشگاکەت ئامادەیە.

## چوونەژوورەوەی بەڕێوەبەر

- ژمارەی مۆبایل: `7501263713`
- وشەی نهێنی: `123456`

**زۆر گرنگ:** یەکسەر لە یەکەم چوونەژوورەوە و پێش ئەوەی سایتەکە بە کەس بڵێیت، وشەی نهێنییەکە بگۆڕە — چونکە ئەم زانیاریانە لەم ڕێنماییەدا نووسراون:
1. لە پەڕەی بەڕێوەبردن → بەکارهێنەران، کۆدی گەڕاندنەوە بۆ خۆت دروست بکە.
2. بچۆ بۆ پەڕەی "وشەی نهێنیت لەبیر چووە؟" و بە کۆدەکە وشەیەکی نوێ دابنێ.

## وێنەی بەرهەمەکان

وێنەی بەرهەمە ئامادەکان لە `public/products/` دان. بۆ بەرهەمی نوێ، لە پەڕەی بەڕێوەبردن بەستەری وێنە دابنێ (دەتوانیت وێنە لە `public/products/` دابنێیت و وەک `products/naw-i-wena.jpg` بینووسیت).

## کێشەت هەیە؟

- **پەڕە سپییە / هەڵە دەردەکەوێت:** لە cPanel لۆگی ئەپەکە ببینە (بەشی Node.js App → لینکی لۆگ).
- **هەڵەی داتابەیس:** دڵنیابە `DATABASE_URL` تەواو و ڕاستە (لەگەڵ `?sslmode=require` لە کۆتاییدا).
